# Ас-Сарир

Историческая 3D-игра с открытым миром о войне народов Дагестана с армией Надир-шаха (1741–1743). Работает прямо в браузере, без сборки и без установки.

## Запуск

Игре нужен любой локальный веб-сервер (модули ES и Web Workers не работают с `file://`):

```
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Поддерживаются последние Chrome, Edge и Firefox с WebGL 2.

## Публикация на GitHub Pages

1. Загрузите содержимое папки в корень репозитория (файл `.nojekyll` обязателен).
2. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
3. Игра откроется по адресу `https://<пользователь>.github.io/<репозиторий>/`.

## Что внутри

- Открытый мир 4 × 4 км: 8 регионов, 18 сёл, Дербент, лагеря шаха, заставы, сторожевые башни, реки и дороги; день и ночь, погода, времена года по актам.
- 9 играбельных народов со своими сёлами, оружием, бонусами и уникальными отрядами.
- Кампания: пролог, четыре акта и эпилог — 40 сюжетных миссий, 27 поручений старейшин, механика «Единство», гонка за четырьмя реликвиями, выборы (Ахмед, Шахман, шамхал) и четыре варианта финала.
- «Летопись» — 60 исторических статей с источниками; спорные факты приведены в двух версиях, вымысел отмечен.
- Сохранения: автосохранение каждые 3 минуты и после заданий, три слота, экспорт и импорт файла.
- Звук и музыка синтезируются через Web Audio: выстрелы с эхом в ущельях, лагерные барабаны, динамическая музыка «исследование → напряжение → бой → победа».

## Структура

```
index.html        точка входа
css/style.css     интерфейс
js/core           движок, ввод, ресурсы, сохранения, звук, прокачка
js/world          рельеф, небо, вода, коллизии, сёла и лагеря, разведка
js/actors         герой, NPC, кони, животные, отряд
js/ai             поведение бойцов и групп
js/combat         оружие, урон, эффекты
js/quests         движок заданий, диалоги, катсцены, летопись
js/ui             HUD, меню, карта, журнал, снаряжение, торговля
data              народы, юниты, миссии, диалоги, катсцены, летопись
assets            3D-модели (glTF) и текстуры
tests             автотесты в headless Chromium
```

## Данные кампании

Все миссии описаны в `data/missions.json`: список шагов (`talk`, `goto`, `ride`, `mount`, `fight`, `escort`, `collect`, `interact`, `chase`, `unity`, `dialog`, `cutscene`, `wait`, `do`), их места (`home:square`, `village:kumukh:mosque`, `poi:pass_samur`, `turchidag:120:40` и т. п.), условия (`if`) и последствия (`done`, `reward`). Диалоги — в `data/dialogs.json`, катсцены — в `data/cutscenes.json`, статьи — в `data/chronicle.json`.

## Тесты

Нужны Python 3 и Playwright с Chromium.

```
python3 tests/run.py --q "quick=avar&q=low" --steps '[["wait",5],["shot","shot.png"]]'
python3 tests/campaign.py avar 300          # прогон всей кампании автоматическим решателем
python3 tests/campaign.py lak 300 m21       # с 21-й миссии
node tests/colliders_test.mjs
```

Параметры адреса для отладки: `?quick=<народ>` — сразу в игру, `&q=low|medium|high` — качество, `&debug=1` — автопрохождение диалогов и `window.QA`, `&x=..&z=..` — точка старта, `&h=` — час, `&w=fog|rain|snow` — погода.
