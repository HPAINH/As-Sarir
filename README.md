## 📜 О чём игра

1741 год. Армия Надир-шаха, взявшая Дели, входит в Дагестан. Вы — молодой воин одного из девяти народов, который проходит путь от защитника родного села до вожака общего ополчения.

Параллельно с шахом вы ищете четыре части легендарного **Золотого трона Сарира**, собираете народы в союз и ведёте их на Андалальскую битву.

> Исторические события, даты и места опираются на источники. Вымышленные герои и сюжетные ходы отмечены в игровой «Летописи».

## ✨ Возможности

| | |
|---|---|
| 🗺️ **Открытый мир 4 × 4 км** | 8 регионов, 18 сёл, Дербент с Нарын-калой, лагеря шаха, заставы, сторожевые башни, реки и мосты |
| 👥 **9 народов** | Аварцы, даргинцы, лакцы, лезгины, табасаранцы, агульцы, рутульцы, цахуры, кумыки — у каждого своё село, оружие, бонус и отряд |
| 📖 **Кампания** | Пролог, 4 акта и эпилог: 40 сюжетных миссий, 27 поручений старейшин, боссы, катсцены |
| 🤝 **«Единство»** | Убедите хотя бы 5 народов из 9 — без этого не начнётся Андалальская битва |
| 👑 **Гонка за реликвиями** | Опоздаете — часть трона достанется персам, и их армия станет сильнее |
| ⚖️ **Выборы** | Судьба Ахмеда, Шахмана и шамхала определяет один из 4 финалов |
| 🗡️ **Бой** | Сабля, кинжал, топор, копьё, кремнёвые ружья с долгой перезарядкой, лук, бой верхом, скрытные убийства |
| 🐎 **Конь и отряд** | 3 породы коней, до 20 бойцов, команды «за мной», «держать», «залп», «в атаку», «отступать» |
| 🌦️ **Живой мир** | День и ночь, туман, дождь, снег, смена сезонов по актам, патрули, охота |
| 📚 **«Летопись»** | 60 исторических статей с источниками; спорные факты — в двух версиях |
| 💾 **Сохранения** | Автосохранение, 3 слота, экспорт и импорт в файл |
| 🎵 **Звук** | Выстрелы с эхом в ущельях, барабаны лагеря, динамическая музыка — всё синтезируется в браузере |

## 🚀 Запуск

**Онлайн:** откройте **[hpainh.github.io/As-Sarir](https://hpainh.github.io/As-Sarir/)** — нужен свежий Chrome, Edge или Firefox.

**Локально:** нужен любой веб-сервер (через `file://` модули не загрузятся):

```bash
git clone https://github.com/HPAINH/As-Sarir.git
cd As-Sarir
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

<details>
<summary><b>📝 Формат миссий</b></summary>

<br>

Кампания целиком описана в `data/missions.json`. Миссия — это список шагов:

```json
{
  "id": "m10", "title": "Перевал", "act": 1,
  "steps": [
    { "type": "talk", "who": "rutul_pass_guard", "at": "poi:pass_samur" },
    { "type": "fight", "at": "poi:pass_samur", "time": 170,
      "waves": [{ "t": 4, "spawn": [{ "g": [["light_cav", 4]], "at": "poi:pass_samur" }] }] }
  ],
  "reward": { "xp": 400, "coins": 40 }
}
```

**Типы шагов:** `talk` · `goto` · `ride` · `mount` · `fight` · `escort` · `collect` · `interact` · `chase` · `unity` · `dialog` · `cutscene` · `wait` · `do`

**Места:** `home:square` · `village:kumukh:mosque` · `poi:pass_samur` · `camp:derbent` · `turchidag:120:40` · `nearby:1`

</details>

<details>
<summary><b>🧪 Тесты</b></summary>

<br>

Нужны Python 3 и Playwright с Chromium.

```bash
python tests/run.py --q "quick=avar&q=low" --steps '[["wait",5],["shot","shot.png"]]'
python tests/campaign.py avar 300        # прогон всей кампании
python tests/campaign.py lak 300 m21     # начиная с 21-й миссии
node tests/colliders_test.mjs
```

Параметры адреса для отладки:

| Параметр | Значение |
|---|---|
| `?quick=avar` | сразу в игру за выбранный народ |
| `&q=low\|medium\|high` | качество графики |
| `&debug=1` | автопрохождение диалогов, объект `window.QA` |
| `&x=..&z=..` | точка старта |
| `&h=21` | час суток |
| `&w=fog\|rain\|snow` | погода |

</details>
